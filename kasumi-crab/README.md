# 香住ガニの店 地図サンプル

個人で作成したサンプルです(実際の案件ではありません)。
兵庫県香美町香住で、香住ガニを食べられる店・買える市場を、JR香住駅から近い順に整理しました。

地図を見る: https://fromwest370.github.io/kasumi-crab/kasumi_crab_map.html

- kasumi_crab_map.html: 一覧と連動する地図
- kasumi_crab_shops.csv: 店の一覧(順位、距離、緯度経度、メモ、確認状況、出典)

## 出典
- 店舗データ: OpenPOI API(https://docs.openpoiapi.com/)。収録元は Overture Maps Foundation(overturemaps.org)、ライセンスは CDLA-Permissive-2.0
- 地図: 国土地理院「地理院タイル」

## 注意
営業状況や価格は変わるため、利用の際は最新の情報を確認してください。
